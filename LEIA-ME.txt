PENA MAXIMA 3D - COMO LIGAR

1) Sobe todos os ficheiros para o GitHub (repositorio pena-maxima) e activa Pages. Abre o link: ja funciona em MODO DE TESTE (contas so neste aparelho).

2) Para login Google, recuperacao de senha por Gmail e desbloqueios reais:
 - console.firebase.google.com > criar projeto > Authentication > Sign-in method: activar Email/Password e Google.
 - Authentication > Settings > Authorized domains: adiciona nimialukeni007-hub.github.io
 - Project settings > Web API Key: copia para config.js em apiKey.
 - Google Cloud > APIs e servicos > Credenciais > ID de cliente OAuth (Web), origem autorizada https://nimialukeni007-hub.github.io : copia para googleClientId.
 - Realtime Database > criar > separador Regras: cola o ficheiro regras-firebase.json (troca COLOCA_AQUI_O_TEU_GMAIL pelo teu Gmail). Copia o URL da base para dbUrl.
 - config.js: admin = o teu Gmail; confirma os precos.

3) Pagamentos: o cliente paga por Express (939632060) ou PayPay (939966303) e carrega em "Ja paguei". Tu abres /admin.html, entras com o teu Gmail e carregas "Aprovar" depois de veres o dinheiro. So ai o item desbloqueia. O pagamento nao se confirma sozinho porque Express/PayPay nao dao API.

Seguranca: a protecao real esta nas regras do Firebase, nao no codigo do site.
